📱 iOS 无线安装（OTA）

无法连电脑时，可在 iPhone 上直接用 Safari 安装，无需数据线。

  • 需使用 Ad Hoc 签名的 IPA，且该设备的 UDID 已加入描述文件。
  • 请用 Safari 打开下方链接（其他浏览器可能无法触发安装）。
  • 若当前在电脑上浏览，可将链接发到手机（邮件、备忘录、微信等），再在 iPhone 的 Safari 中打开。

📋 v2.6.0 更新内容

  • 重大 Bug 修复：修复库存联动、用户认证、账号校验、导出、自动备份、后台管理和通知设置相关问题，提升整体稳定性
  • 账号授权校验修复：服务端统一校验账号激活、试用期、许可证和停用状态，授权失效后不能继续访问业务功能或刷新登录状态
  • UI 更新：优化登录、账户设置、Workspace 详情、统计报表、协议页面、帮助文档等多处界面细节
  • 新增贡献数据页面：新增类似 GitHub 贡献图的贡献总览，展示贡献方格图、活动概览和贡献活动
  • 导出功能重大修复：增强 CSV 字段转义和 PDF 多行字段解析，优化 iOS 导出临时文件处理和 macOS 保存体验
  • 后台管理功能修复：增强用户/许可证状态生效、管理日志、日志筛选、Workspace 敏感操作保护展示等后台能力
  • 停用账号保护：防止被管理员停用的账号自行重新激活，并避免许可证使用人数重复统计
  • 心跳状态提示修复：区分设备数量超限和账号授权失效，避免授权失效时误显示设备数量超限
  • 敏感操作保护：Workspace 默认开启敏感操作保护，防止误改产品库存、误导入数据或误恢复备份
  • 通知设置重大修复：修复五种通知设置在账号切换、跨设备同步、列表高亮、上线/离线提示和轮询性能中的问题
  • 帮助文档搜索：帮助文档页面支持搜索定位匹配内容，并新增原生滚动条
  • 自动备份重大修复：备份写入更稳健，降低异常中断造成损坏文件或混合时刻备份的风险
  • 新增 Workspace 派生功能：可从已有 Workspace 派生新 Workspace，复制产品、客户、供应商、员工基础资料，业务记录保持空白

🚀 核心功能

  • Workspace 工作空间管理 - 支持本地和云端工作空间，数据隔离，团队协作
  • 业务数据管理 - 产品、客户、供应商、员工、采购、销售、退货、进账、汇款
  • 数据统计与分析 - 库存统计、销售分析、财务统计、AI 智能分析
  • 数据管理与备份 - 自动备份、数据导入导出、跨 Workspace 迁移
  • 审计日志 - 完整记录所有操作，支持多维度筛选和详细变更记录
  • 团队协作 - 成员邀请、角色权限、实时权限检查
  • 跨平台支持 - iOS、Android、macOS、Windows 全平台覆盖
